# NLP-Based Sentiment Analysis of Product Reviews

## Project Overview

This project performs sentiment analysis on product reviews using Natural Language Processing (NLP). The system classifies customer reviews as Positive or Negative using TF-IDF feature extraction and Logistic Regression.

## Technologies Used

* Python
* Pandas
* NLTK
* Scikit-learn
* TF-IDF
* Logistic Regression

## Dataset

Amazon Product Reviews Dataset

## Workflow

Review Text → Preprocessing → TF-IDF → Logistic Regression → Prediction

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
